# LinkedIn project image archive

박삼종 본인의 LinkedIn 공개 활동에서 확인한 개발·연구 프로젝트 49건의 첨부 이미지 150장을 게시물 단위로 보존한 아카이브입니다.

- 폴더명: LinkedIn activity ID
- 파일명: 게시물 이미지 순서에 따른 `01.jpg`, `02.jpg` 형식
- 원문: `https://www.linkedin.com/feed/update/urn:li:activity:{폴더명}/`
- 사이트 카드: `linkedin-projects-extended.js`

이미지는 포트폴리오에서 원문 게시물과 함께 제시하며, 외부 CDN 만료와 무관하게 프로젝트 결과 화면을 안정적으로 열람할 수 있도록 이 저장소에 보관합니다.
